intraitR

Morphological trait analysis toolkit for freshwater fish — from landmarks to intraspecific variability.

version1.35.0R≥ 4.1.0licenseGPL-3dependsgeomorph · Rfishmorph

Overview

intraitR is a toolkit for the analysis of morphological traits in freshwater fish, from raw two-dimensional landmark digitization to derived morphological ratios, shape space and functional trait space. Building on the geometric-morphometric framework of geomorph, it adds fish-specific conveniences for ecomorphological analyses: import of landmark data from tpsDig files or generic spreadsheets, Generalised Procrustes Analysis, classical linear ratios of fish ecomorphology, construction and visualisation of morphological and functional trait spaces, quantification of intraspecific morphological variability (ITV), and estimation of measurement error from replicated digitization (Bailey & Byrnes 1990; Fruciano 2016).

It also implements the 11-measurement / 9-ratio digitization protocol of the FISHMORPH database (Brosse et al. 2021), whose database-level tools now live in the companion package Rfishmorph.

Real reference data. The example data set is not simulated: an electrofishing survey of the Saudrune (T-26, Adour-Garonne basin, France), seven species photographed in the field and digitized specimen by specimen with the package's own predictor-assisted application, together with blind repeat digitizations for the measurement-error tools (load_t26_saudrune(), demo("pipeline_T26_saudrune")).

Installation

The package is hosted on GitHub (not yet on CRAN). It requires geomorph (CRAN) and Rfishmorph (installed automatically from GitHub via the Remotes field).

# install.packages("remotes")
install.packages("geomorph")
remotes::install_github("FunTraits/intraitR")

library(intraitR)
Students: the step-by-step procedure to digitize the photographs you received, send the measurements back and analyse them is on the R Packages page.

Workflow

  1. Import landmark coordinates — read_tps() (tpsDig), read_landmarks_csv() (long format), read_landmarks_xlsx() (wide spreadsheets, one X/Y column pair per landmark), or digitize photographs directly with the Shiny app digitize_landmarks() (see below).
  2. Quality-control the configurations before alignment — impute a missing landmark (impute_landmarks()), enforce a head-left / belly-down frame (standardize_orientation()), audit and snap landmarks to the protocol's geometric conventions (correct_landmarks(), correct_geometry()), screen outliers (detect_outliers()). Every correction is recorded in an audit-trail attribute.
  3. Align with Generalised Procrustes Analysis — gpa_fish(); optional allometric correction with correct_allometry().
  4. Derive traits — inter-landmark distances (linear_distances()), ecomorphological ratios (morpho_ratios()) or the FISHMORPH segments and ratios (fishmorph_segments(), fishmorph_ratios()).
  5. Explore spaces — shape space (shape_space()) and functional trait space (trait_space(), PCA/PCoA with log10(x+1) + scaling, missing-value strategies up to missForest), with spider / hull / density displays; project specimens into the global FISHMORPH morphospace (project_fishmorph()).
  6. Quantify variability and error — inter/intraspecific variance partitioning (itv_index()), intraspecific_variability(), repeatability (measurement_error()), landmark-level operator bias (digitization_error()), and how ITV inflates functional richness (bootstrap_functional_space(), compare_functional_richness()).
fish          <- load_t26_saudrune_landmarks()
fish_imputed  <- impute_landmarks(fish)
fish_oriented <- standardize_orientation(fish_imputed)
fish_fixed    <- correct_geometry(fish_oriented)

segments <- fishmorph_segments(fish_fixed)
ratios   <- fishmorph_ratios(segments)

fts <- trait_space(ratios, groups = fish$metadata$species,
                   na_action = "omit", remove_outliers = TRUE)
plot(fts)                        # spider / ellipse display per species

itv <- itv_index(ratios, species = fish$metadata$species)
plot(itv)

Predictor-assisted digitization

digitize_landmarks() opens a bundled Shiny application: from a few calibration clicks, a trained ml-morph model proposes the 19 FISHMORPH anatomical landmarks on each photograph, which the operator reviews, corrects and exports. Every placement is written to an append-only journal, so a workbook can be rebuilt after a crash (consolidate_landmarks()), and photographs are identified by content hash (photo_hash()) rather than by file name.
